# Postur memakai foto asli poster

22 Oktober 2026. Pemilik menyetujui foto poster sebagai visual utama dengan titik interaktif dan pembesaran detail.

## Hasil

- Pilihan atlet: Clarisa Azalia dan Aurellia Cassandra. Karakter ilustratif tidak lagi dimuat oleh Postur.
- Foto yang tersedia: belakang, depan/serong, detail kepala, dan detail tangan. Semuanya berasal dari poster v15 yang diberikan pemilik. Tidak ada foto cermin atau foto yang dibuat ulang.
- Satu file poster asli digunakan bersama oleh semua tampilan. Batas foto ditentukan oleh viewport dan clip dalam tampilan; piksel sumber tidak diubah. Hash SHA256 sumber dan salinan repo sama: `2e688a77dac3365daa85a0e6020ea4c5505d7885f971f521a1836b9a061b4133`.
- Titik dan panduan memiliki koordinat terpisah untuk setiap atlet/foto. Pemilihan anatomi membuka foto terkait. Catatan gambar diganti agar menjelaskan foto saat membidik, bukan pose karakter dengan lengan di samping badan.
- Tombol Perbesar titik membuka dialog berpusat pada area terpilih. Dialog memiliki judul bagian/atlet, tombol tutup native, dan dukungan Escape dari browser.
- Penanda mobile dirapikan ke dua sisi dengan jarak44px dan garis penghubung ke koordinat foto. Tombol pembesaran berada pada panel kontrol agar tidak menutupi nomor pada foto.

## Verifikasi

- Tes foto dijalankan sebelum implementasi: gagal karena masih memuat karakter lama dan belum memiliki detail foto. Sesudah implementasi lulus.
- Suite akhir:55 tes Node lulus,0 gagal. Mencakup hash poster, tampilan tanpa cermin, koordinat/ID tiap atlet, pusat pembesaran, penanda mobile pada tinggi150px, serta materi lain yang sudah ada.
- Area foto menampilkan pesan pemuatan dan kegagalan. Tes memeriksa keadaan memuat, siap, gagal, serta tombol pembesaran yang dinonaktifkan selama foto belum tersedia.
- Delapan viewport foto dirender dari SVG aktual menggunakan Sharp untuk inspeksi, ditambah detail kepala dan peta titik. Batas foto serta anchor tangan/kaki diperbaiki setelah inspeksi. Ini merupakan render komponen foto, bukan screenshot browser.
- Syntax check skrip dan git diff --check bersih.
- Server lokal /lab dan aset foto merespons200.
- Review independen menemukan tombol zoom berpotensi menutupi pin09 saat foto sangat pendek. Tombol dipindah ke panel kontrol, dan regresinya dimasukkan ke tes. Tidak ada temuan penting lain dalam review tersebut.

## Batas saat ini

Akses browser lokal masih dinonaktifkan pada pengaturan Work. Dialog dan tata letak halaman terbaru belum diuji langsung dalam browser/perangkat sentuh. Render komponen dan tes fungsi tidak menggantikan uji itu.

Sumber PNG asli berukuran10.746.210byte, sekitar10,7MB, dan dipakai bersama oleh seluruh pilihan foto. Ukuran unduhan ini belum dioptimalkan. Ukuran asli dipertahankan agar sumber foto dapat diverifikasi tanpa perubahan piksel. Perubahan tetap di draft PR26; belum digabungkan atau dipromosikan ke produksi. Server lokal tetap aktif untuk uji pemilik.
