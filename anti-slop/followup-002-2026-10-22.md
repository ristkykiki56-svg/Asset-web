# Verifikasi workspace mobile Shooting Lab

22 Oktober 2026. Pembaruan PR #26 berdasarkan desain yang disetujui pemilik.

## Perubahan

Kelima materi memakai workspace khusus di bawah 768 px. Visual dan kontrol utama berbagi layar; panel detail dapat digulir tersendiri. Node, ID, state, aset, dan handler simulasi asli dipertahankan. Saat kembali ke desktop, struktur asli dipulihkan.

| Materi | Perbaikan |
|---|---|
| Postur | Figur langsung terlihat, penanda di sisi figur, pemilih anatomi dekat judul. Sudut pandang/model dan penjelasan memakai disclosure. Slider skema tetap dapat dibuka pada mobile dan setelah kembali ke desktop. |
| Pelatuk | Kurva dan tombol putar berada bersama. Mode Arah memuat diagram serta tombol C/B/A dan slider asli. Kontrol native menggantikan target SVG kecil pada mobile. |
| Optik | Posisi kepala dan tampilan lensa dipisahkan. Pemilih parameter menampilkan satu slider terkait. Zoom opsional berfokus pada mata–okuler dan mempertahankan scroll horizontal. |
| Siluet | Pemilih kelompok berada di atas sasaran. Hitungan kelompok/total dan reset dekat gambar; lintasan ilustratif tetap tersedia dalam detail. |
| Peralatan | Senapan dan teleskop dipisahkan, pilihan komponen disaring sesuai gambar. Marker native memiliki area sentuh 44×44 px. Pilihan komponen dipertahankan saat melewati breakpoint. Penjelasan dan penanda posisi tetap tersedia. |

Tombol akhir mengembalikan pengguna ke Postur. Sumber resmi tersedia melalui dialog native dengan tombol tutup dan Escape.

## Bukti verifikasi

- `node --test tests/*.test.mjs`: 41 lulus, 0 gagal pada source akhir.
- `node --check lab-workspace.js` dan `git diff --check`: bersih.
- `tests/lab-workspace.html`: 135 pemeriksaan browser lulus, 0 gagal pada 320/375/390 × 667 px. Termasuk geometri kelima materi, overflow, area slider, sumber, marker peralatan, pin Postur, ID unik, pemulihan desktop 1280 px, slider skema desktop, pilihan komponen, dan navigasi akhir.
- Siklus red/green: fixture awal gagal karena workspace belum ada. Pemeriksaan pilihan peralatan kemudian gagal pada ketiga ukuran; setelah perbaikan pemulihan nilai, fixture lulus.
- Interaksi manual browser: pemutaran kurva mengubah fase; mode Arah terlihat; slider jarak mata melalui End mengubah nilai ke 125; mode lensa tampil; ketuk sasaran memperbarui hitungan; kelompok Ayam mengganti target; detail lintasan terbuka; Enter pada marker okuler mengganti komponen; dialog sumber terbuka dan Escape mengembalikan fokus ke tombol asal; slider Postur dapat diubah lewat keyboard.
- Screenshot diperiksa pada Postur, Pelatuk, kedua mode Optik, Siluet, dan Peralatan. Optik juga diperiksa pada 320 px dan tema gelap. Bukti PNG disimpan dalam output percakapan.
- Review independen menemukan disclosure Postur, state breakpoint, dan target SVG kecil; semuanya diperbaiki. Pemeriksaan desktop tambahan menangkap pemulihan disclosure dan sudah lulus.

## Batas verifikasi

Akses browser lokal dinonaktifkan di pengaturan Work menjelang akhir. Pengulangan `tests/audit-accessibility.html` sudah dimulai tetapi hasil akhirnya belum dibaca; tidak diklaim lulus ulang. Perubahan CSS terakhir hanya menambahkan `margin:auto` pada dialog sumber dan belum diperiksa ulang secara visual. Hasil 135 pemeriksaan tercatat sebelum perubahan margin tersebut. Pengujian ini memakai browser desktop dengan viewport mobile, belum perangkat sentuh fisik atau pembaca layar. Tidak mengklaim audit WCAG penuh.

## Pemeriksaan antislop dalam lingkup perubahan

- Layout: visual utama tidak lagi menunggu scroll panjang; tidak ada overflow halaman pada tiga ukuran fixture.
- Interaksi: pilihan memakai state pressed, input native berlabel, target utama 44 px, dialog native mendukung Escape/fokus kembali.
- Visual: warna kertas/tinta dan aset asli dipertahankan, tanpa aset generatif/dependensi baru atau animasi dekoratif.
- Konten: label model ilustratif dan sumber resmi tetap tersedia. Tidak menambahkan klaim pengukuran atlet.
- Status: siap ditinjau pada draft PR; belum digabungkan atau dipromosikan ke produksi.
