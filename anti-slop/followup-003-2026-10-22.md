# Koreksi Postur setelah uji lokal

Permintaan pemilik: penjelasan titik harus sesuai gambar pada mobile dan desktop; tombol garis perlu memberi perbedaan terlihat; hapus pilihan gambar karakter dan model karakter SVG.

- Sepuluh penjelasan kini membahas bagian tubuh yang ditandai dan sudut pandangnya. Teks tentang WebP/SVG/slider, kartu metrik model, dan klaim penopang yang tidak ditampilkan sudah dihapus dari panel Postur.
- Gambar depan memperlihatkan lengan di samping badan. Penjelasan lengan/siku mengikuti gambar tersebut; anchor siku kiri disesuaikan ke siku, bukan pinggang.
- Checkbox, model karakter prosedural SVG, slider lengkungan/siku, serta kalkulasi indikator terkait dihapus. Hanya karakter biru/merah dan pilihan sudut pandang yang tersedia. SVG tetap menjadi wadah gambar raster dan penanda, bukan model karakter pengganti.
- Tombol bernama Panduan titik menampilkan atau menyembunyikan lingkaran dan garis bantu pada titik terpilih. Nomor pemilih tetap tersedia pada kedua keadaan.
- Bila gambar gagal dimuat, tampil pesan kegagalan; tidak ada pergantian otomatis ke karakter SVG.
- Review independen menangkap subtitle indeks desktop menjadi undefined setelah kode lama dihapus. Subtitle diganti dengan nama sudut pandang; tes render indeks mencakup semua sepuluh entri.

Verifikasi: tes regresi awal gagal sebelum implementasi. Suite Node akhir mencakup render panduan pada empat sudut pandang, perubahan tampil/sembunyi, kesamaan posisi panduan dengan anchor, indeks desktop, penjelasan sepuluh titik, serta penghapusan kontrol model. Syntax check tiga skrip bersih. HTTP lokal /lab mengembalikan 200 dan markup terbaru.

Browser lokal masih dinonaktifkan pada pengaturan Work, sehingga perubahan ini belum diuji ulang secara visual dalam browser. Fixture browser diperbarui mengikuti penghapusan model tetapi belum dijalankan kembali. Hasil 135 pemeriksaan dari revisi sebelumnya tidak diklaim untuk revisi ini.
